## 📊 Sobre o projeto

O **Porsche Sales Dashboard** é um projeto de visualização e análise de dados comerciais desenvolvido a partir de uma planilha Excel (`.xlsx`).

A construção da interface contou com o apoio da inteligência artificial Claude, utilizada para interpretar os requisitos e gerar uma dashboard em HTML a partir de instruções em linguagem natural.

Após a geração inicial, foram realizados ajustes no visual gráfico e na apresentação das informações, incluindo imagens dos modelos Porsche de acordo com os filtros selecionados.

O projeto busca transformar dados comerciais em informações visuais que facilitem a exploração dos resultados e a identificação de padrões de vendas.

## 🎯 Objetivos de negócio

A dashboard foi planejada para responder às seguintes perguntas:

- **Quais são os principais modelos vendidos por cidade?** Identificar os modelos com maior volume de vendas em cada localidade.
- **Qual ano de modelo apresenta maior volume de vendas?** Comparar os resultados por ano do modelo dentro dos dados disponíveis.
- **Quais modelos são mais populares em cada cidade?** Explorar os modelos com maior volume de vendas por localidade.
- **Como as vendas se distribuem por forma de pagamento?** Analisar os registros conforme o método de pagamento selecionado.

## 🔎 Filtros interativos

A dashboard disponibiliza quatro filtros principais para segmentar os dados:

| Filtro | Finalidade |
|---|---|
| **Modelo Porsche** | Selecionar o modelo do veículo. |
| **City** | Analisar os dados por cidade. |
| **Pay Method** | Filtrar as vendas por forma de pagamento. |
| **Model Year** | Explorar as vendas por ano do modelo. |

A combinação dos filtros permite explorar diferentes cenários e comparar os resultados conforme os critérios selecionados.

## 🤖 Processo de desenvolvimento

O desenvolvimento foi realizado com apoio de inteligência artificial, seguindo as etapas abaixo:

1. Preparação da planilha Excel com os dados de vendas.
2. Envio da planilha ao Claude para utilização como fonte de dados.
3. Elaboração de instruções para criar a dashboard em HTML.
4. Definição dos filtros e das perguntas de negócio.
5. Geração inicial da interface com auxílio da IA.
6. Refinamento do visual gráfico e da apresentação dos dados.
7. Inclusão de imagens dos modelos Porsche relacionadas aos filtros.
8. Publicação do projeto no GitHub e disponibilização pelo GitHub Pages.
